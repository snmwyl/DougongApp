## 📖 项目简介

**探秘斗拱** 是一款专注于中国古代建筑核心构件——**斗拱** 的交互式科普Android应用。

本项目突破传统图文展示的局限，采用 **3D模型交互** 技术，让用户能够：
- 🔍 **360°旋转观察** 斗拱的立体结构
- 🖱️ **点击拖拽拼装** 栌斗、华拱、昂三大核心构件
- 🎮 **沉浸式学习** 中国古代木结构建筑的精妙智慧

参赛类别：数媒游戏与交互设计 - 交互媒体设计

## 📱 功能特点

### 🏠 首页 - 文化科普
- 精美文化展示页面
- 内嵌专业斗拱讲解视频（B站科普资源）
- 一键播放，零门槛了解斗拱文化

### 🏛️ 科普模块 - 3D构件详解
| 功能   | 说明                                            |
| ------ | ----------------------------------------------- |
| 栌斗   | 3D模型展示 + 文字科普（位于柱顶，承受上部荷载） |
| 华拱   | 3D模型展示 + 文字科普（向外挑出，承托屋檐）     |
| 昂     | 3D模型展示 + 文字科普（斜向构件，杠杆原理）     |
| 多视角 | 正面、侧面、仰视三种视角快速切换                |

### 🎮 拼装模块 - 交互式学习
| 功能     | 说明                                   |
| -------- | -------------------------------------- |
| 栌斗拼装 | 拖拽底座和上部到指定位置，体验拼装过程 |
| 华拱拼装 | 拖拽前后两部分到圈圈位置，感受悬挑结构 |
| 昂拼装   | 拖拽上下两部分到圈圈位置，理解杠杆原理 |
| 点击高亮 | 点击模型后变为亮橙色，视觉反馈清晰     |
| 拖拽移动 | 手指拖拽即可移动模型位置               |
| 自动吸附 | 将部件拖到对应圈圈附近自动吸附到位     |
| 视角控制 | 拼装过程中可旋转/缩放，全方位观察      |

### 🎨 交互亮点
- ✨ **串行加载**：6个GLB模型逐个加载，避免内存溢出，性能稳定
- 🎯 **拖拽吸附**：直观的物理反馈，提升学习趣味性
- 📹 **内嵌视频**：引用B站专业科普视频，保证内容权威性
- 🖱️ **零门槛**：无需专业知识，点击拖拽即可上手

### 💡 教育意义
通过**亲手拼装**斗拱的三个核心构件（栌斗、华拱、昂），用户可以：
1. 直观理解斗拱的**结构组成**
2. 体验古代工匠的**建造智慧**
3. 感受中国古建筑中**力学与美学的完美结合**

## 🚀 快速开始

### 环境要求
- Android Studio Arctic Fox 或更高版本
- JDK 11 或更高版本
- Android SDK API 21+

### 运行步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/snmwyl/DougongApp.git

2. **用Android Studio打开项目**
   - File → Open → 选择项目文件夹

3. **同步Gradle**
   - 等待自动同步完成
   - 如有提示，点击 Sync Now

4. **运行App**
   - 连接Android手机（开启开发者模式 + USB调试）
   - 或启动模拟器（API 21+）
   - 点击绿色三角形运行

## 📦 生成APK

如需生成可分享的安装包：

1. 菜单栏：`Build` → `Generate Signed Bundle / APK…`
2. 选择 `APK` → `Next`
3. 创建或选择密钥库（.jks文件）
4. 选择 `release` 构建变体
5. 勾选 `V1 + V2` 签名版本
6. 点击 `Finish`

> APK生成路径：`app/build/outputs/apk/release/app-release.apk`

## 🎮 使用说明

### 首页
- 打开App进入文化展示页
- 点击「点击观看讲解视频」播放B站科普视频

### 科普模块
1. 点击底部导航栏 `📖 科普`
2. 点击下方按钮切换构件：栌斗 / 华拱 / 昂
3. 点击视角按钮：正面 / 侧面 / 仰视
4. 拖拽旋转3D模型，多角度观察

### 拼装模块
1. 点击底部导航栏 `🎮 拼装`
2. 点击下方选择要拼装的构件：栌斗 / 华拱 / 昂
3. 部件会显示在场景中
4. **点击部件** → 高亮显示
5. **拖拽部件** → 移动到对应的彩色圈圈
6. **松开** → 自动吸附到位，提示拼装成功
